# Provider evidence — 2026-10-07

Official documentation and synthetic HTTP fixtures only; **no authenticated requests or live eligibility checks**.

- [OpenRouter model properties](https://openrouter.ai/docs/api/api-reference/models/list-all-models-and-their-properties): `GET /api/v1/models` reports per-token price strings, optional request/image/cache/reasoning charges, overrides and `supported_parameters`. Provider documentation also defines `is_free: true` as an exact free endpoint flag (free endpoint variants ignore submitted pricing). The app accepts explicit `is_free: true` or explicit zero prompt/completion prices; if text-relevant request/cache/reasoning prices are present, they must also be zero. Omitted optional price fields are treated as no listed SKU for that charge; non-requested image/audio/web-search prices do not block text-only requests. Unknown fields and any positive applicable/conditional price still block. Model IDs alone are not evidence.
- [OpenRouter API overview](https://openrouter.ai/docs/api/reference/overview), [provider selection](https://openrouter.ai/docs/guides/routing/provider-selection) and [key limits](https://openrouter.ai/docs/api/reference/limits): `POST /api/v1/chat/completions` supports named model, `provider.allow_fallbacks=false`, `provider.require_parameters=true`, and `provider.max_price` (prompt/completion per million tokens; request/image in their own units). The builder sends only named model, text messages, max tokens, optional supported temperature/seed, `stream=false`, and zero-price ceilings. Model-routing `models`/`route`, plugins, tools and BYOK settings are never accepted. `GET /api/v1/key` may return `free_model_daily_requests.used/limit`; `usage_daily` and `limit` are monetary, not request counts. Missing free counters remain unknown.
- [Zen endpoint and pricing tables](https://opencode.ai/docs/zen/): a dated exact-ID allowlist is now sourced from the official pricing table and endpoint table. The allowlist was checked 2026-10-08 and expires 2026-10-15; refresh/review before expiry. `muse-spark-1.3-contributor-free` uses `/responses` and `jev-1.13-free` uses `/systemone`, so these two free-price entries are not executable by this initial chat adapter. Zen also says these offers are limited-time and model-specific data-use/privacy exceptions apply. The page does not document an account quota-counter endpoint; unknown quota remains under the app cap.

Refresh timestamps represent observations, not availability guarantees. The fixture catalog and reply are explicitly synthetic. No named live model is asserted eligible.
